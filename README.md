# Карта воздушных оповещений

Веб-приложение, которое показывает оповещения о воздушной угрозе (БПЛА/шахеды,
ракеты, КАБ) по регионам Украины и России на интерактивной карте. Назначение —
информирование и безопасность гражданских: где сейчас активна угроза и пора
пройти в укрытие.

## Источники данных (оба реальные)

| Страна  | Канал                         | Статус         | Что берём                              |
|---------|-------------------------------|----------------|----------------------------------------|
| Украина | **@kpszsu** (Воздушные Силы)  | официальный    | статусы областей + движения шахедов/БПЛА |
| Россия  | **@radarrussiia**             | неофициальный  | статусы регионов                        |

### ⚠️ О достоверности

- **@kpszsu** — официальный канал Воздушных Сил ВСУ.
- **@radarrussiia** — НЕОФИЦИАЛЬНЫЙ агрегатор. Это не МЧС. Достоверность,
  полнота и своевременность не гарантированы.
- Статусы определяются **парсингом текста** сообщений по ключевым словам
  (укр.: «БпЛА», «🛵», «ракети», «відбій»; рус.: «опасность», «отбой» и т.п.).
  Это эвристика — возможны неточности при необычных формулировках.

### Логика времени (TTL)

Тревога по региону **снимается автоматически**, если новых сообщений по нему
нет дольше заданного окна:

- Украина — 75 минут (угрозы движутся быстро);
- Россия — 2 часа.

То есть «если по региону тихо N часов — с ним всё спокойно», как вы и просили.
Окна задаются константами `UA_TTL_MS` / `RU_TTL_MS` в парсерах.

## Что показывает

- Карта с подсветкой регионов (тревога/спокойно/нет данных).
- **Примерное расположение дронов/шахедов** — маркеры 🛵 (Украина) и ✈️
  (Россия) ставятся по названному в сообщении населённому пункту
  (из справочника `js/places.js`). Если конкретный н.п. не назван — маркер
  ставится по центру области и помечается как «ориентировочно» (приглушённый).
- Панель **«🛵 Шахеды / БПЛА над Украиной»** — активные движения с местом,
  курсом и временем (по данным @kpszsu). Клик по строке центрирует карту.
- Список регионов, сгруппированный по странам, со счётчиками.

> ⚠️ Расположение **приблизительное**: точка привязывается по тексту
> сообщения (название города/района), а не по реальной телеметрии. Это
> «примерно где», а не точные координаты.

## Как это устроено

Страницы Telegram (`t.me/s/...`) не отдают CORS-заголовки, поэтому браузер не
может читать их напрямую. Есть небольшой **локальный бэкенд** на Node
(без зависимостей):

```
server.js          статика + /api/ru-alerts и /api/ua-alerts (кэш 30 сек)
js/parseCommon.js  общие утилиты парсинга + расчёт статусов с TTL
js/places.js       справочник координат населённых пунктов (геокодинг по тексту)
js/ruParser.js     парсер @radarrussiia  (Россия, + расположение дронов)
js/uaParser.js     парсер @kpszsu        (Украина, + шахеды с местом)
```

## Как запустить

Нужен Node.js 18+ (используется встроенный `fetch`).

```bash
node server.js
```

Затем откройте http://localhost:8080

> Просто открыть `index.html` как файл (`file://`) недостаточно — данные
> тянутся через бэкенд, поэтому нужен запущенный `server.js`.

## Настройка

- **Окна снятия тревоги** — `UA_TTL_MS` в `js/uaParser.js`, `RU_TTL_MS` в
  `js/ruParser.js`.
- **Регионы и их распознавание** — координаты в `js/regions.js`, словари
  «стемов» названий в `REGION_STEMS` каждого парсера.
- **Точки населённых пунктов** (для расположения дронов) — справочники
  `UA_PLACES` / `RU_PLACES` в `js/places.js`. Добавляйте сюда города/районы,
  чтобы маркеры ставились точнее.

## Структура

```
index.html          разметка и подключение скриптов
css/styles.css      стили интерфейса
js/regions.js       регионы (UA + RU) с координатами
js/parseCommon.js   утилиты парсинга + TTL-логика статусов
js/places.js        справочник координат населённых пунктов
js/ruParser.js      парсер @radarrussiia (+ расположение дронов)
js/uaParser.js      парсер @kpszsu (+ извлечение движений шахедов)
js/dataSource.js    запрос обоих фидов и нормализация
js/app.js           карта, рендер, панель шахедов, маркеры дронов, обновление
server.js           Node-бэкенд: статика + два API
```

## Чего это НЕ делает (осознанно)

Приложение **не отслеживает позиции конкретных дронов** для наведения. Оно
агрегирует уже опубликованные публично оповещения уровня региона/направления.

## Технологии

- [Leaflet](https://leafletjs.com/) — интерактивная карта.
- CARTO dark basemap + данные OpenStreetMap.
- Node.js (http, fetch) — бэкенд без внешних зависимостей.
- Чистый JavaScript на фронтенде, без сборки.
